# Security policy

RouterPulse is a portfolio and educational system. It has not been audited and
must not secure real assets. Its initial proof model trusts a permissioned
relayer signer. RPC providers may be stale or inconsistent, and confirmation
depth does not eliminate reorg risk.

Do not submit real secrets in issues. Report suspected vulnerabilities privately
to the repository owner. Never use the local Anvil development keys outside
local development.
